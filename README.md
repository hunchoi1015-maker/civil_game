# Civil Game - 문명 전략 보드게임

> React + TypeScript 기반의 턴제 전략 보드게임

## 🎮 게임 소개

Civil Game은 문명(Civilization) 시리즈에서 영감을 받은 턴제 전략 보드게임입니다. 플레이어는 국가를 선택하고 수도를 건설하여, 기술 연구, 도시 관리, 군사 전략을 통해 승리 조건을 달성합니다.

### 주요 특징

- **다양한 승리 조건**: 과학, 문화, 경제, 군사 승리 중 선택
- **6개 국가**: 미국, 로마, 이집트, 중국, 러시아, 독일 (각각 고유 능력)
- **5단계 기술 트리**: 고대부터 현대까지 기술 연구 (피라미드 구조)
- **전략적 전투 시스템**: 부대 카드 기반 전투 (보병/포병/기병/공군 상성)
- **도시 경영**: 건물 건설, 자원 생산, 영토 확장
- **정부 체제**: 6가지 정치 체제 선택 (전제정, 군주정, 민주정 등)
- **청크 기반 맵 탐험**: 안개 속 영토를 탐험하며 확장

## 🚀 시작하기

### 필요 사항

- Node.js 18.x 이상
- npm 또는 yarn

### 설치 및 실행

```bash
# 저장소 클론

cd civil_game

# 의존성 설치
```

## 🎯 게임 규칙

### 게임 진행

게임은 **5단계 턴 시스템**으로 진행됩니다:

1. **차례 시작 (Start)**: 정부 체제 변경
2. **교역 (Trade)**: 교역 수입 수령 및 자원 교환
3. **도시 경영 (City Management)**: 건물/유닛 생산, 문화 수확
4. **이동 (Movement)**: 유닛 이동 및 전투
5. **연구 (Research)**: 기술 연구

모든 단계는 **순차 진행**되며, 선플레이어부터 순서대로 행동합니다.

### 승리 조건

- **과학 승리**: 5단계 기술 "우주 비행" 연구
- **문화 승리**: 문화 트랙 20 달성
- **경제 승리**: 화폐 15개 획득
- **군사 승리**: 적 수도 점령 또는 모든 적 제거

## 🎲 핵심 시스템

### 1. 전투 시스템

부대 카드 기반 전투:

#### 병종 상성
- **포병 → 보병**: 선제공격
- **기병 → 포병**: 선제공격
- **보병 → 기병**: 선제공격
- **공군**: 무상성 (모든 병종에 동시 공격)

#### 전투력
티어별 전투력 (필요 생산력):
- **Tier 1**: 전투력 4 (생산력 2)
- **Tier 2**: 전투력 5 (생산력 3)
- **Tier 3**: 전투력 6 (생산력 4)
- **Tier 4**: 전투력 7 (생산력 5)

**전투력 = 공격력 + 체력**  
예시: Tier 2 (총 5) → 1/4, 2/3, 3/2, 4/1 조합 가능

#### 전장 배치
**사용 가능한 부대 카드 수** (전투 시 손패):
- 유닛 수 또는 도시 기준으로 결정
- 야전: 유닛 수에 따라
- 도시/수도: 최대 6장

#### 배치 제한
**타일당 유닛 최대 개수**:
- 기본: 3개 (개척자 + 군사 유닛 합산)
- 러시아: 4개 (배치 제한 +1)

**전장 배치 ≠ 배치 제한**
- **전장 배치**: 전투 중 사용할 수 있는 부대 카드 수
- **배치 제한**: 한 타일에 놓을 수 있는 유닛의 최대 개수

### 2. 기술 연구

#### 기술 레벨 및 비용

| 레벨 | 시대 | 기술 수 | 비용 (교역) |
|------|------|---------|-------------|
| 레벨 1 | 고대 | 5개 | 6 |
| 레벨 2 | 고전 | 4개 | 11 |
| 레벨 3 | 중세 | 4개 | 15 |
| 레벨 4 | 산업 | 4개 | 21 |
| 레벨 5 | 현대 | 1개 | 26 |

#### 기술 피라미드 규칙

새 기술을 배우려면 **적절한 자리**가 있어야 합니다:

```
피라미드 구조:
        5단계 (1개)
       4단계 (2개)
      3단계 (3개)
     2단계 (4개)
    1단계 (5개)
```

**배치 규칙:**
- **1단계**: 항상 배치 가능 (맨 아래)
- **2단계**: 1단계 기술 2개 위에 놓아야 함
  - 1단계 3개 → 2단계 2개 가능
  - 1단계 4개 → 2단계 3개 가능
- **3단계**: 2단계 기술 2개 위에 놓아야 함
  - 2단계 3개 → 3단계 2개 가능
  - 2단계 4개 → 3단계 3개 가능
- **일반 규칙**: 하위 레벨 기술이 상위 레벨 기술보다 **2개 이상** 많아야 상위 레벨 연구 가능

**특수 규칙:**
- 문명 시작 기술은 **본래 단계에 상관없이 항상 1단계 자리에 배치**
- 예: 로마의 '법계'가 원래 2단계 기술이어도, 시작 기술이므로 1단계에 놓임

**문화 건물:**

- **영토 확장**: 도시 주변 8칸 자동 소유

### 4. 맵 시스템

#### 맵 크기 및 구조
- **크기**: 16×16 표준 맵
- **청크 단위**: 4×4 타일 = 1 청크
- **총 청크 수**: 16개 (4×4 청크 그리드)

#### 자원
- 밀
- 철
- 향료
- 비단

#### 가시성 (안개 시스템)

**게임 시작:**
- 맵의 4개 꼭짓점에 있는 청크만 공개 (각 플레이어 시작 위치)
- 나머지 12개 청크는 안개 속에 숨겨짐

**청크 공개:**
- 유닛이 보이지 않는 청크로 이동 시도 시
- 해당 청크 전체(4×4 타일)가 즉시 공개됨
- 한 번 공개된 청크는 계속 보임

**청크 위치:**
```
청크 배치 (16x16 맵):
[0,0] [1,0] [2,0] [3,0]
[0,1] [1,1] [2,1] [3,1]
[0,2] [1,2] [2,2] [3,2]
[0,3] [1,3] [2,3] [3,3]

시작 공개 청크 (꼭짓점):
- [0,0]: 좌상단
- [3,0]: 우상단
- [0,3]: 좌하단
- [3,3]: 우하단
```
